MyQ Garage Door Opener Via Segmentation model

I built an automated MyQ garage door system that uses real-time computer vision to operate hands-free. A segmentation model first detects the presence of a vehicle in the camera feed, isolating it from the background. Once a vehicle is detected, a ResNet-based classification model identifies the specific car. If the detected car matches an authorized vehicle, an ESP32 microcontroller is triggered to actuate a servo motor that physically presses the garage door button. This system combines deep learning, embedded systems, and mechanical actuation to create a secure, low-latency, and fully automated garage door opener without modifying the existing MyQ hardware.

Key Features

  • Specific Cars have open different doors
  • Plans to incorperate driver location so that it is not soley based on car recogntion

Technologies Used

  • Segmentation Networks
  • ESP32 CircuitPython
  • Python and PyTorch: Programming framework for model development
  • Classification Networks
